# Web Proposal — Khu di tích Từ Lương Xâm

## GitHub Pages

Repository: https://github.com/datcangagency/DatCangxTLX

Website dự kiến sau khi triển khai: https://datcangagency.github.io/DatCangxTLX/

Đây là website tĩnh. Sau khi push nhánh `main`, bật Settings → Pages → Deploy from a branch → `main` → `/ (root)`. File `.nojekyll` giúp phục vụ trực tiếp các tệp HTML, CSS và JavaScript.

## Mở bản local

Mở `index.html` bằng Chrome. Đây là website tĩnh, không cần cài đặt hay chạy server; nội dung và kiểu trình bày nằm trong `index.html`, `styles.css`, `app.js`.
